MangaToAnime

Desktop App · Windows & macOS

Convert manga PDF panels into anime-styled fight scene videos using Gemini image generation and Veo video generation — powered by Electron.

Desktop app only. MangaToAnime is an Electron desktop application and cannot run inside a web browser or on Vercel as a hosted app. Download and install the executable on your computer.
Download Releases View on GitHub

PDF → Panels

Upload manga PDFs, select pages, extract at 300 DPI.

Gemini Automation

Embedded webview automates gemini.google.com for image restyling.

Veo Clips

Generate video clips with seed-frame chaining for continuity.

FFmpeg Export

Stitch clips into MangaFight_[timestamp].mp4 on your Desktop.

Build from source

cd mangaToAnime && npm install && npm start

npm run build:win:unpacked → dist/win-unpacked/MangaToAnime.exe
